# 세탁현황 게시판

## 경로 및 관리

- 게시판: `/laundry-status` (PC·모바일 메뉴 **세탁현황**, 영상 다음. 기존 CMS 메뉴 목록에도 자동 추가)
- 관리자: `/studio` 왼쪽 메뉴 **세탁현황** (싱글톤 문서 `laundryStatusPage`)
- 검색 제외: `noindex, nofollow` 메타 태그를 넣고 사이트맵에서 뺐습니다. 고객 이름은 구글 슬라이드 원본에서 `홍*동`처럼 가려 입력하세요(슬라이드 원본은 링크만 있으면 누구나 열 수 있습니다).
- 안내 배너: 슬라이드 위 진한 녹색 배너. 기본 문구 `현재 시범 운영 중으로, 천안아산점 세탁 현황만 제공됩니다.` Studio의 **안내 배너 문구**로 바꾸고 **안내 배너 표시**를 끄면 숨깁니다.
- 입력 항목: 제목, 설명, **구글 슬라이드 링크**(필수), 자동 넘김(사용 안 함 / 3·5·10·15·30·60초), **자동 새로고침 간격**(1·3·5·10분, 기본 5분)

### 구글 슬라이드 준비

1. 슬라이드 오른쪽 위 **공유** → 일반 액세스를 **링크가 있는 모든 사용자 · 뷰어**로 변경
2. **링크 복사**한 주소(`https://docs.google.com/presentation/d/<ID>/edit…`)를 Studio에 붙여넣고 Publish

‘웹에 게시’ 주소(`/d/e/2PACX…`)는 파일 ID가 아니어서 입력 단계에서 거부합니다. 공유가 ‘제한됨’이면 슬라이드가 보이지 않습니다. 뷰어 다운로드 허용은 필요 없습니다.

## 자동 새로고침 방식

- 다운로드를 막아 둔 슬라이드는 구글이 변경 여부를 알려주지 않으므로, **정해진 간격(기본 5분)마다 슬라이드를 다시 불러옵니다**. 수정 내용은 최대 그 간격 안에 반영됩니다.
- 새 슬라이드를 뒤에서 미리 불러온 뒤 교체하므로 화면이 깜빡이지 않습니다. 새로고침 후에는 첫 슬라이드부터 다시 시작합니다.
- 탭이 보이지 않을 때는 멈추고, 탭으로 돌아오면 간격이 지났을 경우 즉시 새로고침합니다.
- 브라우저는 1분마다 `/api/laundry-status`에서 설정(슬라이드 링크·자동 넘김·새로고침 간격)을 확인하므로, Studio에서 바꾸면 webhook 재검증 후 페이지 재접속 없이 반영됩니다. 이 API는 Sanity 캐시만 읽고 구글에는 요청하지 않습니다.
- 화면 크기: 슬라이드 비율(embed 페이지의 SVG viewBox에서 읽음, 기본 16:9) + 구글 조작 막대 36px로 상자를 맞추고 가장자리 2px를 잘라 검은 여백이 생기지 않게 했습니다. 343~1174px 폭 7가지에서 가장자리 검은 픽셀 0개를 실측했습니다. 구글이 조작 막대 높이를 바꾸면 `EMBED_TOOLBAR_PX`(`src/lib/googleSlides.ts`)를 조정하세요.

## 배포 시 확인

- `/api/revalidate` 대상 경로에 `/laundry-status`, webhook 스크립트 대상 타입에 `laundryStatusPage`를 추가했습니다. 운영 webhook에는 `npm run setup:sanity-webhook`으로 필터를 갱신해야 Studio 수정이 즉시 반영됩니다(미갱신 시 최대 5분).
