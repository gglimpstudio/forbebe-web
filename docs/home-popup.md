# 메인 이미지 팝업 목록

## CMS 관리

`/studio` 왼쪽 메뉴의 **팝업 설정**에서 관리합니다. 독립 문서 유형과 ID는 모두 `homePopup`입니다.

1. **전체 팝업 활성화**를 켭니다. 기본값은 꺼짐입니다.
2. **팝업 목록**에서 팝업을 추가합니다. 드래그로 순서를 바꾸고 항목 메뉴에서 복제·삭제할 수 있습니다.
3. 관리자용 제목, 개별 활성화, 이미지와 이미지 연결 URL을 입력합니다. 이미지 대체 텍스트는 선택 항목입니다.
4. 게시하면 목록 순서대로 하나의 모달에서 표시합니다. 실제 이미지·링크가 없으면 활성화하지 마세요.
5. 기존 숨김 기록을 초기화하려면 해당 항목의 **노출 버전**을 이전에 사용하지 않은 더 큰 정수로 올리고 게시합니다. 일반적인 내용 수정에서는 버전을 유지합니다.

| 항목 | 필드 | 동작 |
| --- | --- | --- |
| 전체 활성화 | `enabled` | 전체 팝업 표시 제어 |
| 팝업 목록 | `items[]` | 추가·삭제·복제·순서 변경 |
| 관리자용 제목 | `items[].title` | 목록 미리보기에만 사용 |
| 개별 활성화 | `items[].enabled` | 해당 항목 표시 여부 |
| 고유 식별자 | `items[].id` | UUID 자동 발급, 읽기 전용. 내용 수정·순서 변경 시 유지 |
| 노출 버전 | `items[].version` | 1부터 시작하는 정수. 변경 시 이전 버전의 숨김 기록 미적용 |
| 이미지·대체 텍스트 | `items[].image`, `image.alt` | 원본 비율 유지. 대체 텍스트는 선택이며 미입력 시 `포베베 안내` 사용 |
| 이미지 연결 URL | `items[].url` | `/pricing` 같은 내부 경로 또는 HTTP(S) 주소 |

목록에는 관리자용 제목, 이미지 썸네일, 활성 상태가 표시됩니다. 복제한 항목에는 새 ID를 발급하며, 목록의 ID 중복도 검증합니다. 필수 자료가 빠지거나 URL이 잘못된 항목은 웹사이트에서 제외합니다. 전체 비활성 또는 유효한 항목 0개이면 모달을 만들지 않습니다.

내부 경로와 사이트의 절대 주소는 현재 탭에서 이동하고 외부 HTTP(S) 주소는 `target="_blank"`, `rel="noopener noreferrer"`로 엽니다. 실행 가능한 스킴, 프로토콜 생략 주소(`//...`), 역슬래시, 제어 문자, 인증정보가 포함된 URL은 거부합니다.

기존 Sanity 캐시 정책은 최대 300초입니다. 즉시 반영을 위해 webhook을 운영 중이라면 기존 `setup:sanity-webhook` 스크립트의 `homePopup` 대상 설정을 적용합니다. 이 작업에서는 운영 배포, CMS 게시, 외부 webhook 변경을 수행하지 않았습니다.

## 표시와 닫기

- 하나의 모달에서 수동 슬라이드로 표시하며 자동 전환하지 않습니다.
- 2개 이상이면 이전·다음 버튼과 `1 / 3` 위치 표시를 제공합니다. 처음·마지막은 순환합니다. 1개가 남으면 탐색과 전체 오늘 숨김을 감춥니다.
- 모바일 이미지 영역에서 좌우 스와이프를 지원합니다. 세로 스크롤과 핀치 확대는 유지합니다.
- 팝업의 선호 너비는 데스크톱·태블릿(768px 이상)에서 `min(50vw, 720px)`, 모바일에서 `100vw - 32px`입니다. 이미지의 원본 비율과 상·하단 조작부의 실제 높이를 함께 계산해 화면 높이에 맞으면 너비도 줄입니다. 읽을 수 있는 최소 너비(화면 범위 내 최대 320px)까지 줄여도 매우 긴 이미지는 카드 내부에서 스크롤합니다. 극도로 낮거나 좁은 화면에서 조작부가 커지면 모달 자체도 스크롤해 모든 조작에 접근할 수 있습니다.
- 상단 조작 줄은 이미지 밖의 투명 영역에 놓이고, 카드와 8px 간격을 둡니다. 왼쪽은 오늘 숨김·전체 오늘 숨김, 오른쪽은 44px 터치 영역의 22px X입니다. 조작부는 이미지 위에 겹치지 않습니다.
- 이미지와 다중 팝업 탐색 줄이 12px 모서리의 카드 하나를 구성합니다. 1개이면 이미지 아래에 별도 영역이 없습니다. 2개 이상일 때만 하단에 이전·현재 위치·다음 탐색을 표시합니다. 상세내용확인 영역과 버튼 문구 입력은 제거했습니다.
- 이미지 전체는 실제 anchor이며 기존 URL·탭·보안 규칙을 사용합니다. 이미지 링크에는 안내 목적을 알리는 접근성 이름이 있습니다. 이동·스크롤·취소된 포인터 동작 뒤의 이미지 클릭은 차단하고 일반 탭, 키보드 Enter, 수정 키/중간 버튼 새 탭 열기는 유지합니다.

| 동작 | 적용 대상 | 기록·결과 |
| --- | --- | --- |
| X, Escape, 팝업 바깥 클릭·터치 | 현재 표시 대상 전체 | 항목별 세션 숨김 후 모달 닫기 |
| 오늘 보지 않기(상단) | 현재 항목 | 오늘 숨김 후 다음 항목. 마지막이면 닫기 |
| 전체 오늘 보지 않기 | 현재 표시 대상 전체 | 오늘 숨김 후 모달 닫기 |
| 이미지 클릭 | 현재 항목의 링크 | 해당 URL 이동. 숨김 기록을 추가하지 않음 |

팝업 바깥에서 시작하고 끝난 클릭·터치는 X와 동일하게 닫습니다. 내부에서 시작해 바깥에서 끝난 드래그·스와이프는 닫기로 처리하지 않습니다. 이미 숨겼거나 비활성·무효인 항목에는 전체 닫기 기록을 추가하지 않습니다. 나중에 추가한 새 항목은 기존 일반 닫기의 영향을 받지 않습니다.

## 저장소·접근성

- 저장소 키: `forbebe:home-popup:<인코딩된 ID>:v<노출 버전>:session` 또는 `:day`.
- 일반 닫기는 `sessionStorage`를 사용해 현재 탭의 세션 동안 유지합니다. 오늘 숨김은 `localStorage`에 방문자의 로컬 달력 날짜를 저장합니다. 다음 날짜에 재방문하면 다시 표시합니다. 24시간 만료 방식이 아니므로 일광절약시간에도 날짜 경계가 맞습니다.
- 세션·오늘 기록 중 하나라도 유효하면 제외합니다. 다른 탭의 오늘 숨김 변경도 열린 모달에 반영합니다.
- 저장소가 거부되면 예외 없이 동작하고 메모리로 클라이언트 탐색 중 숨김을 유지합니다. 저장이 불가능한 환경에서는 새로고침 이후 숨김을 보장할 수 없습니다.
- SSR 및 최초 hydration에는 슬라이드 마크업을 출력하지 않고, 클라이언트에서 저장소 확인 후 유효한 항목만 표시합니다.
- 이름이 지정된 모달 dialog, 배경 비활성화·스크롤 잠금, Tab·Shift+Tab 순환, 좌우 화살표 탐색, Escape 닫기, 기존 포커스·스크롤 복원을 제공합니다.
- 이전·다음 버튼에는 접근성 이름이 있고, 현재 위치와 대체 텍스트를 라이브 영역으로 알립니다. 팝업 내용 영역도 키보드 스크롤이 가능합니다.

## 기존 단일 데이터 호환

비파괴 방식의 초안 전환과 구형 데이터 fallback을 함께 사용합니다.

- 기존 단일 필드(`id`, `image`, `buttonLabel`, `url`)는 CMS 스키마에 숨김·읽기 전용으로 남기며 값을 삭제하거나 덮어쓰지 않습니다. 목록 항목에 이미 저장된 `buttonLabel`도 숨김·읽기 전용으로만 보존하고, 신규 기본값·화면·조회 데이터에서는 제외합니다.
- 목록 전환 전의 게시된 단일 데이터는 웹사이트에서 첫 항목으로 해석합니다. 기존 ID와 버튼·이미지·URL을 유지하고 노출 버전은 1을 사용합니다.
- CMS에서 기존 문서를 열면 기본 폼을 유지하는 입력 래퍼가 `setIfMissing` 패치로 첫 목록 항목과 `listVersion: 1`을 **초안에만** 추가합니다. 이미 있는 목록에는 덮어쓰지 않습니다. 게시 시 관리자가 최종 반영합니다.
- 목록이 `[]`이면 구형 데이터 fallback을 사용하지 않습니다. 목록 전환 마커가 있으면 목록이 비어 있거나 필드 자체를 제거해도 구형 팝업은 복귀하지 않습니다. 전체 비활성도 우선 적용합니다.
- 기존 단일 팝업의 버전 없는 숨김 키는 버전 1에서만 읽습니다. 새 숨김 기록은 모두 버전이 포함된 키로 저장합니다.

CMS 입력 래퍼는 [Sanity의 기본 입력 컴포넌트 위임 방식](https://www.sanity.io/docs/studio/form-components-reference)을 사용합니다. 별도 라이브러리를 추가하지 않았습니다.

최대 크기 축소·상세내용확인 제거의 최신 화면과 검증 결과는 [최신 변경 보고서](./popup-compact/README.md)에 정리합니다. 이전 유동형 크기·이미지 링크 개편 기록은 [유동형 팝업 보고서](./popup-fluid/README.md)에 있습니다. 이전 480px 디자인의 전후 기록은 [이전 보고서](./popup-redesign/README.md)에서 확인할 수 있습니다.
