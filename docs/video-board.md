# 포베베 관련 영상

2026-11-02 디자인 수정: 페이지 제목을 **포베베 영상**으로 바꾸고 설명을 삭제했습니다. 제목과 첫 카드 사이 간격·카드 padding·재생 버튼 크기를 줄이고 고해상도 썸네일과 단계별 대체를 적용했습니다. [변경 치수·실측·새 캡처 및 검증 결과](./video-design/README.md)를 참고하세요. 아래 최초 구현 기록은 당시의 검증 상태입니다.

## 경로 및 관리

- 게시판: `/videos`
- 관리자 목록·등록: `/studio/structure/youtubeVideo` → 새 문서 만들기
- Sanity 문서 타입: `youtubeVideo`
- PC·모바일 공통 메뉴: **영상**. 기존 CMS 메뉴 목록이 있어도 지점소개 다음에 추가됩니다.

유튜브 링크만 필수입니다. 일반 영상(`youtube.com/watch?v=…`), 공유(`youtu.be/…`), 쇼츠(`youtube.com/shorts/…`) 주소를 붙여넣으면 썸네일이 즉시 표시되고, `/api/youtube`가 YouTube oEmbed에서 제목을 조회해 입력합니다. 제목은 직접 수정할 수 있으며, 늦게 도착한 조회 결과가 수동 제목을 덮어쓰지 않습니다. 잘못된 주소는 링크 입력란 아래에 이유를 표시하고 게시를 차단합니다. 비공개·삭제·접속 실패로 제목을 조회하지 못하면 안내 메시지가 표시되고 제목을 직접 입력할 수 있습니다.

Sanity 기본 Publish로 게시하고, 문서를 다시 열어 수정 후 Publish합니다. 문서 작업 메뉴의 Delete로 삭제합니다. 새 이미지 업로드나 별도 영상 파일 저장은 필요하지 않습니다. 유효한 영상이 없으면 `아직 등록된 영상이 없습니다.`를 표시하며 샘플 영상은 노출하지 않습니다.

## 방문자 동작

기존 Container·SectionHeader·Card, Pretendard, 브랜드 색상과 여백을 사용합니다. 썸네일 전체가 하나의 버튼이며, 클릭 또는 키보드 활성화 즉시 같은 카드에 `autoplay=1`, `playsinline=1` 플레이어를 삽입합니다. 초기 HTML에 iframe이 없고, 선택한 카드 하나에만 플레이어를 만듭니다. 다른 카드 선택 시 이전 iframe을 제거하므로 이전 영상도 정지합니다. 각 영상에는 항상 **YouTube에서 보기** 링크를 제공합니다.

유튜브 임베드의 Referer 식별을 위해 iframe에는 `strict-origin-when-cross-origin`을 사용합니다. [YouTube 플레이어 문서](https://developers.google.com/youtube/iframe_api_reference)를 참고했습니다. 방문자의 브라우저 자동 재생 정책, 영상 소유자의 외부 재생 제한은 영향을 줄 수 있습니다.

## 캐시 및 반영

기존 게시판과 동일하게 Sanity의 게시된 문서를 읽고 300초 간격으로 재검증합니다. 조회 정렬은 `_createdAt desc, _id desc`이므로 제목 수정으로 등록 순서가 바뀌지 않습니다.

`/api/revalidate`의 대상 경로에 `/videos`, webhook 설정 스크립트의 대상 문서 타입에 `youtubeVideo`를 추가했습니다. 이미 운영 중인 webhook에는 새 필터를 반영해야 즉시 갱신됩니다. 쓰기 토큰 등이 설정된 환경에서 `npm run setup:sanity-webhook`으로 갱신할 수 있습니다. 이번 작업에서는 운영 webhook을 변경하지 않았습니다.
